# Último turno — El invernadero

**Integrantes:** Hugo Orielso Cañas Lozano y Elkin Sebastián Perez Marquez

Propuesta de un nivel 2D cenital para Godot 4.5. Lina lleva una batería de emergencia al invernadero tras un apagón. La prueba del banco prepara la interacción del clímax. El mapa técnico describe la arquitectura propuesta. El [prototipo jugable](../../godot/project.godot) concentra la lógica en un script y se comprobó con una prueba automática de batería, banco, pasarela, rechazo, riego y salida.
